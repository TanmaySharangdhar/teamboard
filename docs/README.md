# TeamBoard

A collaborative project management app where teams manage boards, lists and cards in real time.

## Status
In development (Phase 0: Planning)

## Planned Features
- [ ] User authentication (signup, login, logout)
- [ ] Workspaces with roles (Owner, Admin, Member)
- [ ] Boards, lists and cards with drag and drop
- [ ] Comments and file attachments
- [ ] Real-time updates with WebSockets
- [ ] Free and Pro plans with payments (test mode)
- [ ] Email notifications

## Tech Stack
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: MySQL, Prisma
- Real-time: Socket.io
- DevOps: Docker, GitHub Actions
