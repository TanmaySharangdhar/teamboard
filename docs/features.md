# TeamBoard Features

## MVP (Must Have)
The smallest working version of the app.

- **Signup and login:** users create an account and sign in securely
- **Boards:** create, rename and delete boards
- **Lists:** add columns (e.g. To Do, In Progress, Done) inside a board
- **Cards:** add, edit and delete tasks inside a list
- **Drag and drop:** move cards between lists and reorder them
- **Persistent data:** everything is saved in the database

## Version 2
Makes it a real team tool.

- **Workspaces:** group boards under a team or project space
- **Roles:** Owner, Admin and Member, each with different permissions
- **Invite members:** invite teammates to a workspace by email
- **Card details:** description, due date, labels and an assignee
- **Comments:** discuss a task on its card
- **File attachments:** upload files to cards
- **Search and filter:** find cards by title, label or assignee

## Version 3
Advanced features.

- **Real-time updates:** when one user moves a card, others see it instantly
- **Presence:** see who is viewing the board right now
- **Notifications:** alerts for assignments and comments
- **Free and Pro plans:** limits on free workspaces, upgrade through payment (test mode)
- **Email reminders:** invites and due-date reminders
- **Dark mode and keyboard shortcuts**

## Out of Scope (for now)
- Mobile app
- Third-party integrations (Slack, Google Calendar)
- Live deployment (the project runs locally)
